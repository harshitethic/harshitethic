# Profile maintenance

This repository is the profile README rendered at https://github.com/harshitethic.

The README is curated manually to highlight verified engineering work, rather than sorting projects by repository push date. The former scheduled updater was retired because it replaced the featured projects with the most recently updated repos and could present stale or misleading telemetry.

## Updating the profile

- Update featured projects when they gain meaningful new functionality, test coverage, or releases.
- Verify linked demos, upstream PR status, and CI before claiming them.
- Update date-stamped GitHub stars, forks, and accepted-PR counts when revising the page.
- Keep secrets, credentials, and private customer details out of all public writeups.
- Prefer specific technical outcomes to activity counters.

The profile header artwork remains in `assets/header.svg`. Legacy generated SVG assets are no longer referenced by the README.
